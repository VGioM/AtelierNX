Réglages

Réglages du jeu

Ces réglages sont pré-remplis dans la fenêtre qui s'ouvre avant le jeu : tu peux toujours les changer là-bas, et ce que tu y choisis apparaît ici. « Par défaut » = le réglage testé par nxnative pour ce jeu.

Réglages forcés (env.txt)

Bloque les réglages : ils l'emportent sur la fenêtre du jeu, qui les affiche grisés. Pour simplement pré-remplir, utilise plutôt « Réglages du jeu ». Une ligne NOM=valeur par réglage. Ces lignes l'emportent sur la fenêtre de réglages du jeu, qui les affiche alors grisées. Laisse vide pour tout régler depuis la fenêtre du jeu.
Exemples : DM_FULLSCREEN=1, DM_FPS_TARGET=60, DM_OPMODE=1 (mode TV), DM_LAUNCHER=0 (sans fenêtre de réglages).
